# Тренер памяти (карточки)

Многоязычное консольное приложение для тренировки памяти с использованием карточек (флеш-карт).  
Позволяет создавать наборы карточек с вопросами и ответами, проводить сессии обучения, отслеживать прогресс и экспортировать данные.

## Особенности
- Создание, редактирование и удаление карточек (вопрос-ответ).
- Группировка карточек в наборы (темы, категории).
- Режим тренировки: показ вопроса, ожидание ответа пользователя, проверка правильности.
- Ведение статистики: количество правильных/неправильных ответов, процент успеха.
- Повторение сложных карточек (с наименьшим процентом правильных ответов).
- Импорт и экспорт наборов карточек в форматы JSON и CSV.
- Цветной вывод в терминале (где поддерживается).
- Поддержка аргументов командной строки для автоматизации.

## Установка и запуск
Для каждого языка требуются соответствующие инструменты и зависимости.

### Запуск на разных языках

1. **Python**  
   Установка: `pip install colorama` (опционально).  
   Запуск: `python flash_cards.py --add "Столица Франции" --answer "Париж" --set "География"`

2. **JavaScript (Node.js)**  
   Установка: `npm install commander chalk`  
   Запуск: `node flash_cards.js --add "Столица Франции" --answer "Париж" --set "География"`

3. **Go**  
   Запуск: `go run flash_cards.go --add "Столица Франции" --answer "Париж" --set "География"`

4. **Rust**  
   Сборка: `cargo build --release`  
   Запуск: `cargo run -- --add "Столица Франции" --answer "Париж" --set "География"`

5. **Java**  
   Сборка: `javac -cp gson.jar FlashCards.java`  
   Запуск: `java -cp .;gson.jar FlashCards --add "Столица Франции" --answer "Париж" --set "География"`

6. **C# (.NET Core)**  
   Установка: `dotnet add package Newtonsoft.Json`  
   Запуск: `dotnet run -- --add "Столица Франции" --answer "Париж" --set "География"`

7. **C++ (Linux)**  
   Сборка: `g++ -std=c++11 -o flash_cards flash_cards.cpp -ljsoncpp`  
   Запуск: `./flash_cards --add "Столица Франции" --answer "Париж" --set "География"`

8. **Kotlin (JVM)**  
   Сборка: `kotlinc -cp gson.jar FlashCards.kt`  
   Запуск: `kotlin -cp .;gson.jar FlashCardsKt --add "Столица Франции" --answer "Париж" --set "География"`

## Использование

Общие аргументы командной строки (везде, где поддерживается):

- `--add <вопрос>` – добавить карточку (требует `--answer` и опционально `--set`).
- `--answer <ответ>` – ответ для карточки (обязательно с `--add`).
- `--set <набор>` – название набора (категория) для карточки (по умолчанию "Общее").
- `--remove <id>` – удалить карточку по ID.
- `--list` – показать все карточки с ID и набором.
- `--train <набор>` – начать тренировку в указанном наборе (если не указан, все карточки).
- `--export-json <файл>` – экспортировать все карточки в JSON.
- `--import-json <файл>` – импортировать карточки из JSON.
- `--export-csv <файл>` – экспортировать в CSV.
- `--stats` – показать статистику по карточкам (правильные/неправильные ответы).
- `--help` – справка.

python flash_cards.py --add "Столица Франции" --answer "Париж" --set "География"
python flash_cards.py --train "География"
